## Featured project: [BEER](https://github.com/JarJarJames/BEER)

A native **macOS app (SwiftUI)** that installs and runs Windows Steam games on Apple Silicon through Apple's Game Porting Toolkit.

- Custom **C#/.NET helper on SteamKit2** (QR sign-in, cloud saves, achievements), driven from Swift over a JSON CLI boundary
- **Bidirectional cloud-save sync** with timestamp + SHA-1 conflict resolution and mandatory backups before every write
- Per-game isolated Wine environments, DLC management, achievement overlay, controller support
- Offline **XCTest** suite, layered architecture, 5+ public releases, MIT licensed
